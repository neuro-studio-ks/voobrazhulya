# Сайт «Воображуля» - детская парикмахерская (Серпухов)

_Создан 20.11.2026 в Work по демо-видео заказчика._

## Структура

- `index.html`, `styles.css`, `main.js` - статический сайт (одна страница).
- `img/*.jpg` - иллюстрации для сайта (сжатые, ~200-300 КБ).
- `img/*.png` - исходники иллюстраций (не используются на странице).
- `serve.mjs`, `package.json` - служебные, для предпросмотра (npm run dev).
  На хостинг их копировать не нужно.

## Важно: фото временные

Все 4 иллюстрации сгенерированы ИИ. На странице стоит пометка
«фото временные, иллюстративные». Перед сдачей заказчику заменить
на реальные фото салона (по чек-листу материалов от заказчика).
После замены пометку `.gallery__note` в index.html убрать.

## Запись онлайн (обновлено 20.11.2026)

Мастер записи из 4 шагов: услуга и дата в календаре -> мастер -> время -> контакты.
- Мастера (выдуманные, для демо): Анна (Пн, Ср, Пт, Вс), Мила (Вт, Чт, Сб),
  Дарья (Пн-Пт). График и имена - в MASTERS в main.js.
- Слоты: 10:00-20:00, шаг 45 минут, последний слот 19:00-19:45.
  Прошедшие дни и время сегодня заблокированы, запись до 2 месяцев вперёд.
- Отправка: WhatsApp (wa.me) или Telegram (t.me/share - выбор чата вручную).
  Для полноценного Telegram-бота нужен отдельный бот - следующий шаг.
- Форс-мажор: после отправки кнопки «Перенести» и «Отменить запись»
  с готовым текстом и деталями записи.
